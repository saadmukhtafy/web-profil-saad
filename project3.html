Lomba Website - Bunis malang online

Detail Project Lomba Website

Deskripsi Project

Project ini merupakan salah satu pengalaman saya dalam mengikuti kompetisi pengembangan website yang diselenggarakan secara online oleh BINUS Malang, dengan kategori lomba Desain Web Development.
Kompetisi ini dilaksanakan secara berkelompok dengan tiga anggota, yaitu Saad, Ega, dan Galang.
Melalui kegiatan ini, kami berkesempatan untuk mengembangkan kemampuan dalam pembuatan website, meningkatkan kreativitas, serta menerapkan pengetahuan di bidang teknologi informasi. Selain itu, kompetisi ini menjadi pengalaman berharga bagi kami dalam membangun kerja sama tim, mengasah kemampuan pemecahan masalah, dan mengembangkan keterampilan di bidang pengembangan website.

Teknologi yang Digunakan

  • HTML
  • CSS
  • JavaScript
  • React.js
  • Next.js
  • MySQL
  • Prisma ORM
  • Docker
  • CNN (Convolutional Neural Network)
  • Leaflet.js
  • OpenStreetMap

Fitur Website

  • Halaman Beranda (Home)
  • Registrasi dan Login Pengguna
  • Dark Mode dan Light Mode
  • AI Appraisal (Penilaian Barang Berbasis AI)
  • Prediksi dan Klasifikasi Barang dengan CNN
  • Sistem Barter Barang
  • Daftar Barang Siap Barter
  • Pengajuan dan Persetujuan Barter
  • Riwayat Transaksi Barter
  • Peta Persebaran Lokasi Barter
  • Sistem EcoSwap Points
  • Katalog Warisan Budaya
  • Dashboard Pengguna dan Admin
  • Manajemen Data Pengguna
